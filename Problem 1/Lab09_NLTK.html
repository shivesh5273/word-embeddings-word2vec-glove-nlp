Natural Language Toolkit (NLTK) is a popular Python Natural Language Python library.
Reference book on NLTK and discussion on NLP:
http://www.nltk.org/book/
http://www.nltk.org/book/ch01.html

http://www.nltk.org/install.html Install nltk from the command prompt:
pip install --user -U nltk
pip install --upgrade nltk # to check for upgrades Note: You will need numpy installed too. This should already be installed with your Anaconda install.
